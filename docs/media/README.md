# Демонстрационные материалы

[Iris Classifier](../../lab1/DEMO.md) · [Runbook Search](../../lab2/DEMO.md) · [Проверки проекта](../validation.md)

Материалы показывают фактические результаты реализации: HTTP-контракт, модель и индекс, контроль качества, CI/CD и Kubernetes. Галереи каждой лабораторной содержат подписи и ссылки на JSON-источники.

## Форматы

| Путь | Содержимое |
|---|---|
| `labN/*.jpg` | Снимки OpenAPI и просмотрщика результатов в браузере |
| `shared/*.jpg` | Общие подтверждения, включая страницу GitHub Actions |
| `labN/*.mp4` | Видеообзоры последовательности проверок, H.264, 30 секунд |
| `labN/*.gif` | Анимированные предпросмотры для Markdown |
| `sources/*.json` | Реальные ответы API, вывод команд и сохранённые результаты развёртывания |
| `index.html` | Автономный просмотрщик с теми же исходными данными |
| `manifest.json` | Перечень материалов, источники и SHA-256 файлов |

Локальные API и команды выполнены для записи материалов. Учебное развёртывание, promotion и rollback представлены сохранёнными артефактами запуска [37905104404](https://github.com/Ingaleee/itmo-mlops/actions/runs/37905104404). В этих материалах показан проверенный выпуск, а не непрерывное наблюдение за кластером. Версии и digest оставлены для сопоставления с исходными артефактами.

Просмотрщик визуализирует исходные данные; его оформление не является интерфейсом GitHub, kubectl или терминала. Видеообзоры последовательно показывают снимки экранов с фактическими результатами. Они не выдают сохранённую историю релиза за новое развёртывание.

Дополнительные снимки OpenAPI и GitHub Actions получены напрямую с соответствующих страниц в браузере. Общий pipeline относится к обеим лабораторным и хранится одним файлом.

## Обновление

Инструменты находятся в [`scripts/media/`](../../scripts/media/). Для сбора требуется Python-окружение с зависимостями обеих лабораторных; приложения и тесты выполняются в отдельных процессах. Команды ниже выполняются из корня репозитория.

```bash
python scripts/media/collect.py
```

Сборщик обучает Iris, собирает Search, запускает тесты и quality gate, сравнивает повторную сборку и сохраняет реальные HTTP-ответы. API слушают только localhost и останавливаются в `finally`.

Для включения результатов учебного развёртывания передайте ранее скачанные артефакты успешного workflow и сохранённый JSON трёх Deployment:

```bash
python scripts/media/build_gallery.py \
  --teaching-artifacts path/to/workflow-artifacts \
  --deployments path/to/owned-deployments.json
python scripts/media/write_docs.py
python -m http.server 8765 --bind 127.0.0.1 --directory docs/media
```

Откройте `http://127.0.0.1:8765/index.html`. Снимайте каждый экран через браузер: полную страницу для галереи и viewport для видео. Названия файлов соответствуют `lab` и `slug` из `sources/pages.json`. Размещайте JPEG в `docs/media/labN/`, одинаковые по размеру viewport-кадры — в отдельном временном каталоге `labN/`.

Для кодирования нужны Pillow и FFmpeg или пакет `imageio-ffmpeg`; они используются только инструментами документации и не входят в runtime сервисов.

```bash
python scripts/media/assemble.py \
  --ffmpeg path/to/ffmpeg \
  --video-frames path/to/viewport-captures
```

Сборщик создаёт MP4 и GIF, полностью декодирует видео для проверки целостности и записывает манифест. Перед публикацией проверьте читаемость снимков, ссылки галерей и отсутствие credentials в источниках.

## Новая лабораторная

Для `labN/` добавьте экраны с проверяемым результатом и явным источником, два коротких сценария в `assemble.py` и ссылку на `DEMO.md` в README. Медиа хранятся в соответствующем `docs/media/labN/`; общие сведения остаются в этой инструкции. Не добавляйте повторяющиеся снимки без отдельного проверяемого свойства.
